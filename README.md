## Aim:
To design a user-friendly food delivery mobile application named FoodFlow using Figma with four layouts: Splash Screen, Home Screen, Restaurant Details and Cart & Checkout.

## Algorithm:
1. Open Figma and create a new design file.
2. Create a suitable brand logo and colour scheme for FoodFlow.
3. Design the Splash Screen with the application logo and Get Started button.
4. Design the Home Screen with a search bar, promotional banner, food categories and restaurant listings.
5. Create the Restaurant Details screen with food images, menu items, ratings and prices.
6. Design the Cart and Checkout screen with selected items, quantity controls and price details.
7. Apply suitable typography, colours, icons, buttons and card layouts.
8. Maintain consistency and proper alignment across all four screens.
9. Review and finalize the mobile application layouts.
